# whmcs-cac

WHMCS Configuration-as-Code (workspace skeleton)

This repository is a workspace skeleton generated from a workstation blueprint. It contains state YAML, CLI skeleton, Playwright adapters, infra examples and runbooks to manage a WHMCS self-hosted installation via declarative files.

See `docs/blueprint/WHMCS_Configuration_As_Code_Workstation_Blueprint.md` for the full blueprint (initial copy).
